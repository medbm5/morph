Metamorphosis converts and edits files from a holographic ring that opens under your cursor, mid-drag. For Windows and Linux. Free, open source, and completely offline — your original is never touched.

Extras for power users

  • Chain and save recipes. PDF → JPG → square crop → background, as one segment.
  • Same features in the terminal. morph convert --to png *.heic
  • Add your own segments. A short TOML file wraps any local tool — ImageMagick, FFmpeg, pandoc.
  • Right-click entries in Explorer, Dolphin, Nautilus, Nemo and Thunar.
  • Undo the last job — outputs go to the Recycle Bin or Trash.
  • GPU video encoding with NVENC, Quick Sync, AMF or VA-API.

How it works

  1. Start dragging

    Pick up one file, several, or a folder in your file manager — as if you were moving it.

  2. Tap a key

    Tap Shift, Ctrl or Alt. You don't need to hold it. Tap another key to switch rings, or Esc to cancel.

  3. Drop on a segment

    Or press 1–7. The ring collapses into a pulse and confirms “✓ SAVED”. Tools like Crop or Annotate open an editor first.

  4. Find it next to the original

    photo.jpg stays as it was. The result is saved beside it as photo.png — tools add a word, like photo Cropped.jpg. Drag that one to keep going.

Install

Metamorphosis runs in the background with a tray icon. Heavy extras (LibreOffice conversions, face and text detection, HEIC) download only when you first use them.

winget

winget install morph

MSI installer

Download Metamorphosis_x.y.z_x64_en-US.msi from the latest release and run it. For a portable copy, turn on portable mode in Settings.

Windows 10 22H2 or later, x64. If SmartScreen warns about a new publisher, check the release checksum first.

Flathub

flatpak install flathub io.github.medbm5.morph

AppImage

chmod +x Metamorphosis_x.y.z_amd64.AppImage
./Metamorphosis_x.y.z_amd64.AppImage

Debian and Ubuntu (.deb)

sudo apt install ./Metamorphosis_x.y.z_amd64.deb

Arch Linux (AUR)

yay -S morph-bin

Files for AppImage and .deb are on the releases page. On X11 you get the full drag-and-tap experience. On Wayland, read the next section first.

On Wayland, the ring works a little differently

Wayland stops apps from reading your keyboard globally, seeing the cursor over other windows, or opening a window wherever they like. That's good for security, but it means Metamorphosis can’t pop up under your cursor while you drag in another app.

So on Wayland you drag files onto the drop dock — a small target you keep at a screen edge — and the ring opens there. You can also use the right-click entry in your file manager, or log into an X11 session for the full experience.

Questions

Are my files uploaded anywhere?

No. Every conversion and tool runs on your computer. Metamorphosis only goes online to check for updates (which you can turn off) and to download optional components you ask for.

Will it change or delete my original file?

No. Results are always new files saved next to the original, with a name like photo Cropped.jpg. If a name is taken, a number is added. Only the Move action touches originals, and only because you asked it to.

The keys clash with my setup. Can I change them?

Yes. Each ring's key can be changed in Settings. Some Linux window managers use Alt for dragging windows; that only applies when Alt is held as you press the mouse button, so tapping it mid-drag is safe — but you can pick another key.

Why do some segments say "Install component"?

Office conversions use LibreOffice, face and text detection use small local AI models, and HEIC needs a separate decoder. They're downloaded once, on first use, to keep the main install small.

Can I use it without dragging?

Yes. Right-click files in Explorer, Dolphin, Nautilus, Nemo or Thunar, or use the morph command line. The ring can also be driven with 1–7, arrow keys, Enter and Esc.

Can I add my own segments?

Yes. Put a short TOML recipe in your config folder and it appears in the ring for matching files. Recipes can wrap any command-line tool installed on your machine.

Why “Metamorphosis”?

It’s named after Philip Glass’s album Metamorphosis, the way Stands in JoJo’s Bizarre Adventure are named after songs and albums. Its Stand stats:

Is this Tangerine for Windows?

No. Metamorphosis is an independent open-source project inspired by the drag-to-convert idea of Tangerine for Mac. It isn't affiliated with Tangerine or its developer. If you're on a Mac, try Tangerine.

How much does it cost?

Nothing. Metamorphosis is free and open source, with no conversion limits.
